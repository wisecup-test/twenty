### Rules

- **R-CANVAS-001** SHOULD: Canvas animation hooks SHOULD use requestAnimationFrame for smooth 60fps rendering and properly cancel frames on cleanup.

### Verify

```bash
# Find custom effect hooks following naming pattern
find . -path '*/hooks/use-*.ts' -type f | grep -E '(halftone|canvas|layout|effect)' | wc -l

# Verify requestAnimationFrame and canvas context usage
grep -r 'requestAnimationFrame\|canvas\.getContext' --include='use-*.ts' | wc -l

# Verify cleanup logic in useEffect
grep -r 'useEffect.*return.*=>.*cancel' --include='use-*.ts' packages/twenty-website-new/src/sections/ | wc -l
```

**Accept when:**
- At least 3 custom effect hooks exist following the 'use-[effect-name]' naming pattern in website sections
- All canvas-based effect hooks properly implement cleanup logic using useEffect return functions
- Effect hooks are colocated within 'hooks/' subdirectories of their consuming components or sections

<enforcement>
Claude Code MUST NOT skip or defer verification. All canvas animation hooks MUST comply with requestAnimationFrame patterns and cleanup requirements before acceptance.
</enforcement>
