<rule_activation id="0a784b1f-96a7-411c-9921-937a05809fee" title="Standardize Test File Colocation with Source Code: Story Files Use" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files matching `**/*`. Test files and story files must be colocated with source code using __tests__ and __stories__ directories to improve discoverability, maintainability, and CI/CD automation.
</rule_activation>

### Rules

- **R-COLOC-001** MUST: Story files MUST use the naming convention `<ComponentName>.stories.tsx`
- **R-COLOC-002** MUST: All test files with `.test.ts` or `.test.tsx` extensions MUST be located within `__tests__` directories adjacent to their source code
- **R-COLOC-003** MUST: All Storybook story files MUST be located within `__stories__` directories adjacent to their components
- **R-COLOC-004** MUST: Test runner configuration MUST use default discovery patterns without custom `testMatch` overrides for `__tests__` directories
- **R-COLOC-005** MUST: No test files MAY exist in top-level `test/` directories separate from source code
- **R-COLOC-006** SHOULD: Test utilities and shared fixtures SHOULD be centralized in shared test utility packages (e.g., `@twenty/test-utils`) rather than duplicated across `__tests__` directories
- **R-COLOC-007** SHOULD: Build tools SHOULD be configured to explicitly exclude `__tests__` and `__stories__` directories from production bundles

### Verify

```bash
# Count __tests__ directories
find packages -type d -name '__tests__' | wc -l

# Verify all test files are properly located in __tests__
find packages -type f \( -name '*.test.ts' -o -name '*.test.tsx' \) | grep -v '__tests__' || echo 'All test files properly located'

# Count __stories__ directories
find packages -type d -name '__stories__' | wc -l

# Verify test runner configuration uses default discovery
grep -r 'testMatch\|testRegex' --include='*.config.{js,ts}' packages/ || echo 'Using default test discovery'
```

**Accept when:**
- All test files with `.test.ts` or `.test.tsx` extensions are located within `__tests__` directories
- All Storybook story files are located within `__stories__` directories adjacent to their components
- Test runner configuration uses default discovery patterns without custom `testMatch` overrides
- No test files exist in top-level `test/` directories separate from source code
- Story files follow the `<ComponentName>.stories.tsx` naming convention

<enforcement>
Claude Code MUST NOT skip or defer verification. All test file locations and naming conventions MUST be validated before accepting code changes. Violations MUST be flagged and corrected.
</enforcement>
