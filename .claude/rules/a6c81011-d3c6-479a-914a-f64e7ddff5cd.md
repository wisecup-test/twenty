These rules are ALWAYS ACTIVE for all TypeScript/JavaScript modules in packages/twenty-front/src/modules, component libraries in packages/twenty-website-new/src, utility modules in packages/twenty-zapier/src/utils, field input components, theme and styling modules, and hook modules.

### Rules

- **R-BARREL-001** MAY: Modules MAY use barrel exports (index files that aggregate multiple submodules) to simplify import paths for consumers.
- **R-BARREL-002** MUST: Use named exports rather than default exports to improve refactoring safety and IDE support.
- **R-BARREL-003** SHOULD: Group exports by component type (inputs, displays, layouts) in separate index files for component libraries.
- **R-BARREL-004** SHOULD: Document the public API contract in comments within index files, noting any deprecations or usage guidelines.
- **R-BARREL-005** SHOULD: Consider using TypeScript's 'export type' for type-only exports to optimize bundle size.
- **R-BARREL-006** MUST NOT: Import directly from implementation files outside of test files (*.test.ts, *.spec.ts, __stories__/*) unless covered by exceptions.

### Exceptions

- **EXC-001**: Direct imports from implementation files are permitted in test files (*.test.ts, *.spec.ts, __stories__/*) for testing internal behavior.
- **EXC-002**: Migration periods when refactoring existing modules to new export patterns.

### Verify

```bash
# Check for direct component imports (should find none outside test files)
grep -r "from.*\/components\/[^/]*\/[^'\"]*\.tsx" --include="*.ts" --include="*.tsx" --exclude-dir=node_modules --exclude-dir=__stories__ | grep -v "index\.tsx" || echo 'No direct component imports found'

# Count index files to verify barrel exports exist
find packages/*/src -name 'index.ts' -o -name 'index.tsx' | wc -l

# Detect circular dependencies
npx madge --circular --extensions ts,tsx packages/twenty-front/src packages/twenty-website-new/src
```

**Accept when:**
- All module directories containing public components or utilities have index.ts/tsx files
- No direct imports from implementation files are found outside of test files (grep verification passes)
- Circular dependency analysis shows zero circular dependencies between modules
- TypeScript compilation succeeds without errors related to missing or incorrect exports
- All public components and utilities are properly exported from their respective index files
