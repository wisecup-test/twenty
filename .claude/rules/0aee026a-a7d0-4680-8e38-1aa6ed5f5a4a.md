<rule_activation id="0aee026a-a7d0-4680-8e38-1aa6ed5f5a4a" title="Standardize Module Export Patterns for Component and Utility Libraries: Module Exports Organized" applies_to="**/*">
These rules are ALWAYS ACTIVE for all module and library development within the codebase, including all TypeScript/JavaScript modules in packages/twenty-front/src/modules, component libraries in packages/twenty-website-new/src, utility modules in packages/twenty-zapier/src/utils, field input components, theme and styling modules, and hook modules.
</rule_activation>

### Rules

- **R-MOD-001** SHOULD: Module exports SHOULD be organized by functional domain (components, utils, hooks, types) with separate index files for each subdomain.
- **R-MOD-002** SHOULD: Use named exports rather than default exports to improve refactoring safety and IDE support.
- **R-MOD-003** SHOULD: Create index.ts/tsx files in each module directory that export the public API surface.
- **R-MOD-004** SHOULD: For component libraries, group exports by component type (inputs, displays, layouts) in separate index files.
- **R-MOD-005** SHOULD: Use TypeScript's 'export type' for type-only exports to optimize bundle size.
- **R-MOD-006** SHOULD: Document the public API contract in comments within index files, noting any deprecations or usage guidelines.

### Exceptions

- **EXC-001**: Direct imports from implementation files are permitted in test files (*.test.ts, *.spec.ts, __stories__/*) for testing internal behavior.
- **EXC-002**: Migration periods when refactoring existing modules to new export patterns.

### Verify

```bash
# Check for direct component imports bypassing index files
grep -r "from.*\/components\/[^/]*\/[^'\"]*\.tsx" --include="*.ts" --include="*.tsx" --exclude-dir=node_modules --exclude-dir=__stories__ | grep -v "index\.tsx" || echo 'No direct component imports found'

# Count index files in module directories
find packages/*/src -name 'index.ts' -o -name 'index.tsx' | wc -l

# Detect circular dependencies
npx madge --circular --extensions ts,tsx packages/twenty-front/src packages/twenty-website-new/src
```

**Accept when:**
- All module directories containing public components or utilities have index.ts/tsx files
- No direct imports from implementation files are found outside of test files (grep verification passes)
- Circular dependency analysis shows zero circular dependencies between modules
- TypeScript compilation succeeds without errors related to missing or incorrect exports
