These rules are ALWAYS ACTIVE for all files implementing custom visual effects in the design system.

### Rules

- **R-CANVAS-001** MUST: Canvas-based visual effects MUST be encapsulated in custom React hooks following the naming pattern 'use-[effect-name]-[canvas|backdrop]'

### Verify

```bash
# Verify canvas hooks follow naming convention
grep -r "use-.*-canvas\|use-.*-backdrop" packages/twenty-website-new/src --include="*.ts" --include="*.tsx"

# Verify Canvas 2D API usage
grep -r "getContext\('2d'\)" packages/twenty-website-new/src --include="*.ts" --include="*.tsx"

# Run canvas and backdrop related tests with coverage
npm run test -- --testPathPattern="canvas|backdrop" --coverage
```

**Accept when:**
- All custom visual effects requiring pixel manipulation are implemented as React hooks using Canvas API
- Canvas hooks follow consistent naming conventions (use-[effect-name]-[canvas|backdrop]) and encapsulate rendering logic separately from component structure
- Canvas elements include proper cleanup in useEffect return callbacks and respond appropriately to theme/viewport changes
- Canvas elements have appropriate ARIA labels and text alternatives for accessibility
- Performance monitoring shows no rendering regressions on target devices

<enforcement>
Claude Code MUST NOT skip or defer verification. All canvas-based visual effects MUST follow the established hook pattern and pass automated tests before acceptance.
</enforcement>
