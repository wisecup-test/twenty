<rule_activation id="09996489-9a75-4868-a679-2ba9d1865b1f" title="Standardize Module Export Patterns for Component and Utility Libraries: Field Input Components" applies_to="**/*">
These rules are ALWAYS ACTIVE for all module and library development within the codebase, including all TypeScript/JavaScript modules in packages/twenty-front/src/modules, component libraries in packages/twenty-website-new/src, and utility modules in packages/twenty-zapier/src/utils.
</rule_activation>

### Rules

- **R-MOD-001** MUST: Field input components and UI meta-types MUST be exported through their respective module index files to establish clear component boundaries.
- **R-MOD-002** MUST: Use named exports rather than default exports to improve refactoring safety and IDE support.
- **R-MOD-003** SHOULD: Group exports by component type (inputs, displays, layouts) in separate index files for component libraries.
- **R-MOD-004** SHOULD: Document the public API contract in comments within index files, noting any deprecations or usage guidelines.
- **R-MOD-005** MAY: Use TypeScript's 'export type' for type-only exports to optimize bundle size.

### Exceptions

- **EXC-001**: Direct imports from implementation files are permitted in test files (*.test.ts, *.spec.ts, __stories__/*) for testing internal behavior.
- **EXC-002**: Migration periods when refactoring existing modules to new export patterns.

### Verify

```bash
# Check for direct component imports bypassing index files
grep -r "from.*\/components\/[^/]*\/[^'\"]*\.tsx" --include="*.ts" --include="*.tsx" --exclude-dir=node_modules --exclude-dir=__stories__ | grep -v "index\.tsx" || echo 'No direct component imports found'

# Count index files in module directories
find packages/*/src -name 'index.ts' -o -name 'index.tsx' | wc -l

# Detect circular dependencies
npx madge --circular --extensions ts,tsx packages/twenty-front/src packages/twenty-website-new/src
```

**Accept when:**
- All module directories containing public components or utilities have index.ts/tsx files
- No direct imports from implementation files are found outside of test files (grep verification passes)
- Circular dependency analysis shows zero circular dependencies between modules
- TypeScript compilation succeeds without errors related to missing or incorrect exports
