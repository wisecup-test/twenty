<rule_activation id="050324cb-f416-43d0-942e-96000f17d809" title="Standardize Test File Colocation with Source Code: Test Files Colocated" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files in the codebase. Test files must be colocated with source code in __tests__ subdirectories adjacent to the modules they test, and Storybook stories must be colocated in __stories__ directories.
</rule_activation>

### Rules

- **R-COLOC-001** MUST: Test files MUST be colocated with source code in __tests__ subdirectories adjacent to the modules they test.
- **R-COLOC-002** MUST: All test files with .test.ts or .test.tsx extensions MUST be located within __tests__ directories.
- **R-COLOC-003** MUST: All Storybook story files MUST be located within __stories__ directories adjacent to their components.
- **R-COLOC-004** MUST: Test runner configuration MUST use default discovery patterns without custom testMatch overrides for __tests__ directories.
- **R-COLOC-005** MUST: No test files MUST exist in top-level test/ directories separate from source code.
- **R-COLOC-006** SHOULD: Build tools SHOULD be configured to explicitly exclude __tests__ and __stories__ directories from production builds.
- **R-COLOC-007** SHOULD: ESLint rules SHOULD be implemented to enforce test file naming conventions and directory structure.
- **R-COLOC-008** MAY: Legacy code being migrated MAY temporarily maintain separate test directories during transition (EXC-001).
- **R-COLOC-009** MAY: Third-party library wrappers MAY maintain test structure matching upstream conventions (EXC-002).

### Verify

```bash
# Count __tests__ directories
find packages -type d -name '__tests__' | wc -l

# Verify all test files are properly located in __tests__
find packages -type f \( -name '*.test.ts' -o -name '*.test.tsx' \) | grep -v '__tests__' || echo 'All test files properly located'

# Count __stories__ directories
find packages -type d -name '__stories__' | wc -l

# Verify test runner configuration uses default discovery
grep -r 'testMatch\|testRegex' --include='*.config.{js,ts}' packages/ || echo 'Using default test discovery'

# Verify no test files in top-level test/ directories
find packages -path '*/test/*.test.ts' -o -path '*/test/*.test.tsx' | grep -v '__tests__' || echo 'No misplaced test files in top-level test/ directories'
```

**Accept when:**
- All test files with .test.ts or .test.tsx extensions are located within __tests__ directories
- All Storybook story files are located within __stories__ directories adjacent to their components
- Test runner configuration uses default discovery patterns without custom testMatch overrides
- No test files exist in top-level test/ directories separate from source code
- Build tool configurations explicitly exclude __tests__ and __stories__ directories from production builds
- ESLint rules enforce test file location and naming conventions

<enforcement>
Claude Code MUST NOT skip or defer verification. All test files must be validated against the colocation rules before accepting code changes. CI pipeline MUST fail if test files are found outside __tests__ directories. ESLint errors MUST block pull request merges. Automated comments MUST guide developers to correct structure on violations.
</enforcement>
