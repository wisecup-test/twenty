<rule_activation id="3226b64d-c7de-4bf8-b191-f1a351e68531" title="Adopt Canvas-Based Custom Visual Effects for Design System Theming: Canvas Based Hooks" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files implementing custom visual effects in the design system using Canvas-based React hooks.
</rule_activation>

### Rules

- **R-CANVAS-001** MUST: Canvas-based hooks MUST handle cleanup and resource disposal in useEffect return callbacks to prevent memory leaks.

### Verify

```bash
# Verify canvas hook naming conventions and usage
grep -r "use-.*-canvas\|use-.*-backdrop" packages/twenty-website-new/src --include="*.ts" --include="*.tsx"

# Verify Canvas 2D context initialization
grep -r "getContext\('2d'\)" packages/twenty-website-new/src --include="*.ts" --include="*.tsx"

# Run canvas and backdrop related tests with coverage
npm run test -- --testPathPattern="canvas|backdrop" --coverage
```

**Accept when:**
- All custom visual effects requiring pixel manipulation are implemented as React hooks using Canvas API
- Canvas hooks follow consistent naming conventions and encapsulate rendering logic separately from component structure
- Canvas elements include proper cleanup in useEffect return callbacks and respond appropriately to theme/viewport changes
- Canvas hooks handle resource disposal to prevent memory leaks
- All canvas elements include appropriate ARIA labels and text alternatives for accessibility

<enforcement>
Clause R-CANVAS-001 is MANDATORY. Claude Code MUST verify cleanup and resource disposal patterns in all canvas-based hooks before approving implementation. Performance monitoring and accessibility audits are required. Violations trigger automatic rejection during code review.
</enforcement>
