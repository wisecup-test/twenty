<rule_activation id="4bb26271-7149-42b2-82af-61ba06b0a7c0" title="Standardize Field Input Hooks Pattern for Record Field UI Components: Field Input Hooks" applies_to="packages/twenty-front/src/modules/object-record/record-field/ui/meta-types/input/**">
These rules are ALWAYS ACTIVE for all field input components in the twenty-front package, specifically within the record-field UI meta-types input module.
</rule_activation>

### Rules

- **R-FIH-001** MAY: Field input hooks MAY share common utilities or base hooks for cross-cutting concerns.
- **R-FIH-002** MUST: All field input hooks follow the naming convention `useOpen[FieldType]FieldInput` for hooks.
- **R-FIH-003** MUST: All field input components follow the naming convention `[FieldType]FieldInput` for components.
- **R-FIH-004** MUST: Hooks be placed in `packages/twenty-front/src/modules/object-record/record-field/ui/meta-types/input/hooks/`.
- **R-FIH-005** MUST: Components be placed in the parallel `packages/twenty-front/src/modules/object-record/record-field/ui/meta-types/input/components/` directory.
- **R-FIH-006** MUST: Each field input component use its corresponding dedicated hook.
- **R-FIH-007** SHOULD: Hooks return consistent interface patterns (e.g., open handlers, state values, callbacks) to maintain API predictability across field types.
- **R-FIH-008** MAY: Simple field types (text, number, boolean) that require minimal state management and do not benefit from dedicated hooks are exempt from this pattern (EXC-001).

### Verify

```bash
# Count field input hooks following naming convention
find packages/twenty-front/src/modules/object-record/record-field/ui/meta-types/input/hooks -name 'useOpen*FieldInput.tsx' | wc -l

# Verify hooks are used in components
grep -r 'useOpen.*FieldInput' packages/twenty-front/src/modules/object-record/record-field/ui/meta-types/input/components/ | wc -l

# Verify directory structure exists
test -d packages/twenty-front/src/modules/object-record/record-field/ui/meta-types/input/hooks && test -d packages/twenty-front/src/modules/object-record/record-field/ui/meta-types/input/components && echo 'Structure valid'
```

**Accept when:**
- All field input hooks follow the `useOpen[FieldType]FieldInput` naming pattern and are located in the hooks directory
- Each field input component in the components directory uses its corresponding dedicated hook
- The directory structure maintains separation between `hooks/` and `components/` within the meta-types/input module
- Hooks return consistent interface patterns across field types
- New field types added to the record-field system follow the established pattern
