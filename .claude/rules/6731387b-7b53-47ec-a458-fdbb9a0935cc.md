<rule_activation id="6731387b-7b53-47ec-a458-fdbb9a0935cc" title="Adopt Jest as Standard Testing Framework for TypeScript Components: Teams Use Jest" applies_to="**/*.ts,**/*.tsx">
These rules are ALWAYS ACTIVE for all TypeScript packages in the monorepo. Jest is the standard testing framework for unit tests, integration tests, and component tests across all TypeScript code.
</rule_activation>

### Rules

- **R-JEST-001** MUST: All TypeScript test files MUST use Jest as the testing framework.
- **R-JEST-002** MUST: Test files MUST follow the naming convention `__tests__/*.test.ts` or `__tests__/*.test.tsx`.
- **R-JEST-003** MUST: Each package containing TypeScript code MUST include Jest as a dependency in package.json.
- **R-JEST-004** MUST: Each package with TypeScript code MUST have a valid jest.config.js or jest.config.ts file.
- **R-JEST-005** MAY: Teams MAY use Jest's snapshot testing capabilities for UI component regression testing.
- **R-JEST-006** SHOULD: Test utilities, mocks, and fixtures SHOULD be organized in `__tests__/helpers` or `__tests__/fixtures` directories.
- **R-JEST-007** SHOULD: Shared test utilities SHOULD be extracted to a common package (@twenty/test-utils) for reuse across packages.

### Verify

```bash
# Verify all test files use Jest framework
find packages -type f \( -name '*.test.ts' -o -name '*.test.tsx' \) | xargs grep -L 'from.*jest' | wc -l | grep -q '^0$'

# Verify Jest is declared as a dependency in all packages
grep -r '"jest":' packages/*/package.json | wc -l | awk '{if($1>0) exit 0; else exit 1}'

# Verify minimum number of test files following convention
npm run test -- --listTests | grep -E '__tests__/.*\.test\.ts$' | wc -l | awk '{if($1>=11) exit 0; else exit 1}'
```

**Accept when:**
- All TypeScript test files use Jest framework and follow `__tests__/*.test.ts` naming convention
- Each package with TypeScript code includes Jest as a dependency and has a valid jest.config file
- CI pipeline successfully executes Jest test suites for all packages and reports coverage metrics

<enforcement>
Claude Code MUST verify Jest adoption by running the verification commands above. Pull requests with non-Jest test files, incorrect naming patterns, or missing Jest configuration MUST be rejected. Violations are automatically blocked from merging by CI/CD pipeline checks.
</enforcement>
