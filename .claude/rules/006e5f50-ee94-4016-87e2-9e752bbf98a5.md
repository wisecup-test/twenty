<rule_activation id="006e5f50-ee94-4016-87e2-9e752bbf98a5" title="Adopt Jest as Standard Testing Framework for TypeScript Components: Test Files Located" applies_to="**/*.test.ts,**/*.test.tsx">
These rules are ALWAYS ACTIVE for all TypeScript test files in the monorepo across all packages (twenty-zapier, twenty-front, etc.).
</rule_activation>

### Rules

- **R-JEST-001** MUST: Test files MUST be co-located with the source code they test, following the pattern: `src/<module>/__tests__/<filename>.test.ts`
- **R-JEST-002** MUST: All TypeScript packages in the monorepo MUST use Jest as the testing framework for unit tests, integration tests, component tests, and authentication/authorization flow testing.
- **R-JEST-003** MUST: Test files MUST use the `.test.ts` or `.test.tsx` extension and be located in `__tests__` directories adjacent to source code.
- **R-JEST-004** MUST: Each package containing TypeScript code MUST include Jest as a dependency and maintain a valid `jest.config.js` or `jest.config.ts` file.
- **R-JEST-005** SHOULD: Shared test utilities, mocks, and fixtures SHOULD be extracted to a common package (`@twenty/test-utils`) for reuse across packages.
- **R-JEST-006** SHOULD: Jest configuration SHOULD be centralized in the monorepo root with individual packages extending the shared configuration.
- **R-JEST-007** MAY: Legacy packages migrating from another testing framework MAY temporarily maintain dual test infrastructure during the transition period (EXC-001).

### Verify

```bash
# Verify all test files import or use Jest
find packages -type f \( -name '*.test.ts' -o -name '*.test.tsx' \) | xargs grep -L 'from.*jest' | wc -l | grep -q '^0$'

# Verify Jest is declared as a dependency in all packages
grep -r '"jest":' packages/*/package.json | wc -l | awk '{if($1>0) exit 0; else exit 1}'

# Verify test files follow __tests__/*.test.ts naming convention
npm run test -- --listTests | grep -E '__tests__/.*\.test\.ts$' | wc -l | awk '{if($1>=11) exit 0; else exit 1}'
```

**Accept when:**
- All TypeScript test files use Jest framework and follow `__tests__/*.test.ts` naming convention
- Each package with TypeScript code includes Jest as a dependency and has a valid `jest.config.js` or `jest.config.ts` file
- CI pipeline successfully executes Jest test suites for all packages and reports coverage metrics
- Test files are co-located with source code in `src/<module>/__tests__/` directories
- No non-Jest test files exist in the codebase (except approved exceptions)

<enforcement>
Claude Code MUST NOT skip or defer verification of these rules. All pull requests introducing or modifying test files MUST pass Jest verification checks before merging. Violations MUST be flagged and blocked by CI/CD pipeline automation.
</enforcement>
