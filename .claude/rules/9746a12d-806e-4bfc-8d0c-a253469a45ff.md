<rule_activation id="9746a12d-806e-4bfc-8d0c-a253469a45ff" title="Adopt Jest as Standard Testing Framework for TypeScript Components: Typescript Test Files" applies_to="**/*.test.ts">
These rules are ALWAYS ACTIVE for all TypeScript test files in the monorepo.
</rule_activation>

### Rules

- **R-JEST-001** MUST: All TypeScript test files MUST use Jest as the testing framework and MUST be placed in `__tests__` directories with `.test.ts` extension

### Verify

```bash
# Verify all test files import or use Jest
find packages -type f -name '*.test.ts' -o -name '*.test.tsx' | xargs grep -L 'from.*jest' | wc -l | grep -q '^0$'

# Verify Jest is declared as a dependency in packages
grep -r "\"jest\":" packages/*/package.json | wc -l | awk '{if($1>0) exit 0; else exit 1}'

# Verify test files follow __tests__/*.test.ts naming convention
npm run test -- --listTests | grep -E '__tests__/.*\.test\.ts$' | wc -l | awk '{if($1>=11) exit 0; else exit 1}'
```

**Accept when:**
- All TypeScript test files use Jest framework and follow `__tests__/*.test.ts` naming convention
- Each package with TypeScript code includes Jest as a dependency and has a valid `jest.config` file
- CI pipeline successfully executes Jest test suites for all packages and reports coverage metrics

<enforcement>
Claude Code MUST NOT skip or defer verification. All TypeScript test files MUST comply with Jest framework requirements and naming conventions before code is accepted.
</enforcement>
