<rule_activation id="c5dfb766-4628-4713-90b6-62529d0074c3" title="Adopt Jest as Standard Testing Framework for TypeScript Components: Packages Containing Typescript" applies_to="**/*">
These rules are ALWAYS ACTIVE for all TypeScript packages in the monorepo. Jest is the standard testing framework for all TypeScript components, utility functions, integration tests, and component tests.
</rule_activation>

### Rules

- **R-JEST-001** MUST: All packages containing TypeScript code MUST include Jest configuration and dependencies in their package.json
- **R-JEST-002** MUST: Test files MUST follow the standardized naming convention `__tests__/*.test.ts` or `__tests__/*.test.tsx`
- **R-JEST-003** MUST: Each TypeScript package MUST have a valid jest.config.js or jest.config.ts file
- **R-JEST-004** SHOULD: Shared test utilities SHOULD be extracted to common packages (e.g., @twenty/test-utils) for reuse across packages
- **R-JEST-005** SHOULD: Test utilities and fixtures SHOULD be organized in `__tests__/helpers` or `__tests__/fixtures` directories
- **R-JEST-006** MAY: Legacy packages migrating from another testing framework may temporarily maintain dual test infrastructure during transition period (EXC-001)

### Verify

```bash
# Verify all test files use Jest framework
find packages -type f -name '*.test.ts' -o -name '*.test.tsx' | xargs grep -L 'from.*jest' | wc -l | grep -q '^0$'

# Verify Jest is configured as a dependency in packages
grep -r "\"jest\":" packages/*/package.json | wc -l | awk '{if($1>0) exit 0; else exit 1}'

# Verify test files follow naming convention
npm run test -- --listTests | grep -E '__tests__/.*\.test\.ts$' | wc -l | awk '{if($1>=11) exit 0; else exit 1}'
```

**Accept when:**
- All TypeScript test files use Jest framework and follow `__tests__/*.test.ts` naming convention
- Each package with TypeScript code includes Jest as a dependency and has a valid jest.config file
- CI pipeline successfully executes Jest test suites for all packages and reports coverage metrics

<enforcement>
Clause Code MUST NOT skip or defer verification. All TypeScript packages MUST be verified to have Jest configuration and dependencies before code is merged. Pull requests with non-Jest test files or incorrect naming patterns MUST be blocked from merging.
</enforcement>
