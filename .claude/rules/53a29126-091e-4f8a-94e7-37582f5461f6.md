<rule_activation id="53a29126-091e-4f8a-94e7-37582f5461f6" title="Adopt Storybook Stories for UI Component Documentation and Visual Testing: Storybook Stories Integrated" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files matching reusable UI components in the twenty-front package, particularly record field input components and shared component libraries.
</rule_activation>

### Rules

- **R-SB-001** SHOULD: Storybook stories SHOULD be integrated into the CI/CD pipeline for visual regression testing.
- **R-SB-002** SHOULD: All reusable UI input components in the twenty-front package SHOULD have corresponding story files.
- **R-SB-003** SHOULD: Story files SHOULD follow the naming convention `{ComponentName}.stories.tsx` and be located in `__stories__` directories.
- **R-SB-004** SHOULD: Story files SHOULD export valid Storybook Meta objects.
- **R-SB-005** SHOULD: Component story updates SHOULD be included in the definition of done for component changes.
- **R-SB-006** MAY: Components MAY be exempted if deprecated and scheduled for removal within the current sprint (EXC-001).
- **R-SB-007** MAY: Components MAY be exempted if they are temporary prototypes or experimental features not intended for production (EXC-002).

### Verify

```bash
# Count story files in the codebase
find packages/twenty-front/src -name '*.stories.tsx' | wc -l

# Verify story files export valid Storybook Meta objects
grep -r "export default.*Meta" packages/twenty-front/src/**/__stories__/*.stories.tsx

# Verify Storybook builds successfully
npm run storybook:build && test -d storybook-static
```

**Accept when:**
- All reusable UI input components have corresponding story files in `__stories__` directories
- Story files follow the naming convention `{ComponentName}.stories.tsx` and export valid Storybook Meta objects
- Storybook builds successfully without errors and generates static output
- Visual regression tests run in CI pipeline and catch component changes
- New components added to the codebase include corresponding story files before merge

<enforcement>
Claude Code MUST NOT skip or defer verification. All new reusable UI components MUST include corresponding Storybook story files. CI pipeline MUST fail if components are added without stories. Pull requests MUST be blocked until story files are added and reviewed.
</enforcement>
