<rule_activation id="04809b87-948f-4fd8-a9b6-6c5f633238ae" title="Adopt Custom Canvas-Based Visual Effects Hooks for Design System Theming: Effect Hooks Expose" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files implementing custom canvas-based visual effects hooks within the design system.
</rule_activation>

### Rules

- **R-CANVAS-001** SHOULD: Effect hooks SHOULD expose minimal, focused APIs that return refs or state needed by the consuming component.
- **R-CANVAS-002** SHOULD: Effect hooks SHOULD follow the naming convention 'use-[effect-name]' for consistency.
- **R-CANVAS-003** SHOULD: Effect hooks SHOULD be colocated in 'hooks/' subdirectories within component folders.
- **R-CANVAS-004** MUST: All canvas-based effect hooks MUST properly implement cleanup logic using useEffect return functions.
- **R-CANVAS-005** SHOULD: Effect hooks SHOULD use useRef for canvas elements and useEffect for lifecycle management.
- **R-CANVAS-006** SHOULD: Effect hooks SHOULD leverage requestAnimationFrame for consistent animation patterns.
- **R-CANVAS-007** SHOULD: Canvas effects SHOULD be decorative only or provide equivalent ARIA labels and semantic HTML alternatives for accessibility.
- **R-CANVAS-008** SHOULD: Effect hooks SHOULD include TypeScript types for hook return values and configuration parameters.

### Verify

```bash
# Count custom effect hooks following naming pattern
find . -path '*/hooks/use-*.ts' -type f | grep -E '(halftone|canvas|layout|effect)' | wc -l

# Verify canvas and animation frame usage in hooks
grep -r 'requestAnimationFrame\|canvas\.getContext' --include='use-*.ts' | wc -l

# Verify cleanup patterns in effect hooks
grep -r 'useEffect.*return.*=>.*cancel' --include='use-*.ts' packages/twenty-website-new/src/sections/ | wc -l
```

**Accept when:**
- At least 3 custom effect hooks exist following the 'use-[effect-name]' naming pattern in the website sections
- All canvas-based effect hooks properly implement cleanup logic using useEffect return functions
- Effect hooks are colocated within 'hooks/' subdirectories of their consuming components or sections
- Canvas effect hooks include proper TypeScript types for return values and configuration
- All canvas-based effects provide accessibility considerations (ARIA labels or semantic alternatives)
