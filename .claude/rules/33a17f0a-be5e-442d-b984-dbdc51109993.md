<rule_activation id="33a17f0a-be5e-442d-b984-dbdc51109993" title="Standardize Module Export Patterns for Component and Utility Libraries: Consumers Not Import" applies_to="**/*">
These rules are ALWAYS ACTIVE for all TypeScript/JavaScript modules in packages/twenty-front/src/modules, packages/twenty-website-new/src, packages/twenty-zapier/src/utils, field input components, theme and styling modules, and hook modules.
</rule_activation>

### Rules

- **R-MOD-001** MUST_NOT: Consumers MUST NOT import directly from internal implementation files; all imports MUST use the public module exports.
- **R-MOD-002** MUST: All module directories containing public components or utilities MUST have index.ts/tsx files that export the public API surface.
- **R-MOD-003** SHOULD: Use named exports rather than default exports to improve refactoring safety and IDE support.
- **R-MOD-004** SHOULD: Group exports by component type (inputs, displays, layouts) in separate index files for component libraries.
- **R-MOD-005** SHOULD: Document the public API contract in comments within index files, noting any deprecations or usage guidelines.
- **R-MOD-006** MAY: Use TypeScript's 'export type' for type-only exports to optimize bundle size.

### Exceptions

- **EXC-001**: Direct imports from implementation files are permitted in test files (*.test.ts, *.spec.ts, __stories__/*) for testing internal behavior.
- **EXC-002**: Migration periods when refactoring existing modules to new export patterns.

### Verify

```bash
# Check for direct component imports bypassing index files
grep -r "from.*\/components\/[^/]*\/[^'\"]*\.tsx" --include="*.ts" --include="*.tsx" --exclude-dir=node_modules --exclude-dir=__stories__ | grep -v "index\.tsx" || echo 'No direct component imports found'

# Count index files in module directories
find packages/*/src -name 'index.ts' -o -name 'index.tsx' | wc -l

# Detect circular dependencies
npx madge --circular --extensions ts,tsx packages/twenty-front/src packages/twenty-website-new/src
```

**Accept when:**
- All module directories containing public components or utilities have index.ts/tsx files
- No direct imports from implementation files are found outside of test files (grep verification passes)
- Circular dependency analysis shows zero circular dependencies between modules
- TypeScript compilation succeeds without errors related to missing or incorrect exports
